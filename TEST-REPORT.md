- Проверка бизнес-логики: поиск по нескольким статусам

## 5. Анализ результатов

### Позитивные сценарии (CRUD)
- **Результат:** Все 5 позитивных тестов пройдены успешно
- **Вывод:** Основные операции с питомцами работают корректно

### Негативные сценарии
- **Результат:** Все 5 негативных тестов не пройдены
- **Вывод:** API не проверяет входные данные на корректность:
  - Не отклоняет отрицательный ID
  - Не обрабатывает переполнение числа
  - Не проверяет обязательность поля `name`
  - Не проверяет, что имя не пустое
  - Не поддерживает поиск по нескольким статусам

### Критический дефект
- **BUG-002:** Сервер падает с ошибкой 500 при отправке ID = 9223372036854775808
- **Риск:** Злоумышленник может использовать это для DoS-атаки
